## ✨ Features

### 💰 **Investment Planning**
- **Business Setup Costs**: Civil works, equipment, furniture, initial inventory
- **Working Capital Analysis**: Cash flow requirements and operational reserves
- **Marketing Budget Planning**: Promotional and launch cost calculations
- **Real-time Investment Totals**: Automatic capital requirement computation

### 🏢 **Premises & Operations**
- **Rent & Utilities Management**: Monthly operational costs with inflation modeling
- **Capacity Planning**: Average ticket sizes for in-store and delivery operations
- **Maintenance & Insurance**: Ongoing facility and protection cost budgeting
- **Annual Cost Projections**: 12-month premises expense forecasting

### 📈 **Cash Flow Analysis**
- **Monthly Projections**: Detailed month-by-month financial forecasting
- **Growth Modeling**: Configurable sales growth rates and trend analysis
- **Cost Structure Tracking**: COGS, labor, and operational expense monitoring
- **Profitability Analysis**: Net income calculations with tax considerations

### 📊 **Financial Results Dashboard**
- **Performance Metrics**: Revenue, profit margins, and ROI calculations
- **Break-even Analysis**: Time to profitability projections
- **Investment Returns**: Payback period and NPV analysis
- **Interactive Visualizations**: Professional charts and data representation

## 🎯 **Quick Start**

### **Option 1: Use Online (Recommended)**
Simply visit **[https://dexhub.github.io/Resto-calculator/](https://dexhub.github.io/Resto-calculator/)** and start planning immediately!

### **Option 2: Run Locally**
```bash
# Clone the repository
git clone https://github.com/Dexhub/Resto-calculator.git

# Navigate to the directory
cd Resto-calculator

# Open in your browser
open restaurant-business-calculator-pro.html
# or
python -m http.server 8000
# Then visit http://localhost:8000
```

## 🛠️ **Technology Stack**

- **Frontend**: Pure HTML5, CSS3, JavaScript (ES6+)
- **Charts**: Chart.js 4.4.0 for interactive data visualization
- **Icons**: Font Awesome 6.4.0 for professional iconography
- **Fonts**: Inter & JetBrains Mono for optimal readability
- **Storage**: Local Storage API for data persistence
- **Design**: Modern glassmorphism with responsive layout
